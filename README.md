# ntu-skills

PUDA machine skills for machines in the NTU lab.

Before a physical NTU workflow whose safety or correctness depends on visible setup, load the central `puda-machine-vision-validation` skill, confirm `puda env current` is `ntu`, and use an NTU-scoped machine/camera profile. Never reuse BEARS or IMRE camera calibration, workspace geometry, credentials, or prior confirmations.
